# دليل رفع لوحة التحكم والـ API لـ OROR TUNNEL 🚀

عزيزي الآدمن، لقد تم إعداد وتجهيز كافة أكواد لوحة التحكم والـ API داخل مجلد `/backend/` في المشروع لتتمكن من رفعها فوراً على مجلد استضافتك على Serv00:
`https://elias555.serv00.net/orortunnel/`

---

## 📁 محتويات المجلد الجاهز للرفع (`/backend/`):
1. **`index.php`**: المحرك الرئيسي والـ API الذي يقرأ منه التطبيق في الخلفية (يجلب السيرفرات، الـ Configs، الإشعارات، التحديثات الإجبارية، ووضع الصيانة).
2. **`admin.php`**: لوحة تحكم ويب احترافية بالكامل للتحكم الشامل في:
   - إضافة وتعديل وحذف **السيرفرات والراوترات (Nodes)** المتاحة.
   - إضافة ونشر **الـ Configs والثغرات** (فودافون، أورنج، اتصالات، WireGuard, SSH, V2Ray, SlowDNS).
   - إرسال **إشعارات وتنبيهات فورية** تظهر للعملاء داخل التطبيق.
   - مولد **QR Code والـ Deep Links** لتثبيت الـ Config بنقرة واحدة.
   - تفعيل/إيقاف **وضع الصيانة الإجباري**.

---

## 🌐 خطوات الرفع والتشغيل على Serv00:

1. افتح لوحة التحكم الخاصة بك في Serv00 أو مدير الملفات (File Manager).
2. انتقل إلى المجلد: `public_html/orortunnel/` (أو المجلد المطلوب).
3. ارفع الملفات التالية مباشرة إلى ذلك المجلد:
   - `index.php`
   - `admin.php`
4. افتح لوحة التحكم الويب عبر متصفحك:
   `https://elias555.serv00.net/orortunnel/admin.php`
5. **بيانات الدخول الإفتراضية للوحة التحكم:**
   - **اسم المستخدم:** `admin`
   - **كلمة المرور:** `admin12345`

بمجرد رفع الملفات وإضافة أي Config أو سيرفر من لوحة التحكم، سيقوم التطبيق بقراءتها ومزامنتها تلقائياً بدون الحاجة إلى إعادة بناء التطبيق أو استخراج APK جديد! ⚡
